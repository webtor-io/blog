Самая крупная порция обновлений за год: полностью переработанная self-hosted версия, новое приложение для терминала и уведомления, которые теперь живут на сайте, а не только в почте.

## Self-hosted: полная перезагрузка

Если вы держите [собственный Webtor](https://github.com/webtor-io/self-hosted) — это то самое обновление. Первое за девять месяцев и самое масштабное за всю историю проекта.

**Всё, что умеет webtor.io, теперь умеет и ваш инстанс.** Библиотека, долгосрочное хранилище Vault, лента уведомлений, Stremio, доступ по WebDAV и S3 — self-hosted больше не «облегчённая версия». Это тот же Webtor, только на вашем железе. Подключаются и AI-рекомендации, и распознавание фильмов и сериалов через TMDB — с постерами и описаниями на вашем языке; для каждой из этих функций нужен свой API-ключ.

**Мастер-пароль.** Задайте его — и инстанс только ваш: сайт не покажет ничего, пока пароль не введён, а сменить его можно прямо в профиле. То, что нужно, если сервер смотрит в интернет.

**Работает на ARM.** Raspberry Pi, ARM-серверы, Apple Silicon — один Docker-образ на всех. Малинка в углу комнаты теперь может быть полноценным Webtor.

Из приятных мелочей: MKV-файлы стали нормально запускаться, а сам образ теперь собирается из готовых частей — обновления будут выходить быстрее.

## Знакомьтесь: webtor-cli

Webtor теперь есть и в терминале. Новое приложение [webtor](https://github.com/webtor-io/webtor-cli) стримит и скачивает торренты по обычному HTTP — без торрент-клиента и без ожидания всего файла:

```console
$ webtor play "magnet:..."   # сразу в VLC
$ webtor download <id>       # с докачкой
$ webtor library             # библиотека в терминале
```

Это полноценное приложение, а не просто набор команд: запустите `webtor` без аргументов — и попадёте в интерактивные меню. Библиотека и Vault листаются, файлы выбираются, загрузки идут в фоне, ставятся на паузу и продолжаются. Мышь работает. О законченной загрузке придёт уведомление на рабочий стол.

Подключается к аккаунту webtor.io (одноразовый код — и терминал залогинен, как у GitHub CLI), к RapidAPI или к вашему self-hosted инстансу.

Установка в одну строку:

```console
$ brew install webtor-io/tap/webtor
```

Готовые сборки для Linux, macOS и Windows — плюс Docker-образ — на [странице релизов](https://github.com/webtor-io/webtor-cli/releases/latest).

## Уведомления прямо на сайте

В шапке сайта появился колокольчик. Предупреждения Vault — «файл истекает через 7 дней» — и другие события аккаунта теперь видны там и на отдельной странице уведомлений: со счётчиком непрочитанных и кнопкой «прочитать всё». Раньше всё это уходило только на почту — теперь почта запасной канал, а не единственный. Старые письма тоже подтянулись в ленту, так что вся история в одном месте.

## Письма на вашем языке

Все письма от Webtor — напоминания Vault, подтверждение адреса — теперь приходят на языке вашего аккаунта. Одиннадцать языков, а не только английский.

## Разработчикам: Go SDK

Вышел [официальный Go SDK](https://github.com/webtor-io/api-sdk-go) для JSON API Webtor — на нём построен консольный клиент. Логин, загрузка торрентов, докачка, работа с библиотекой — всё в несколько строк на Go.

## Стабильность

- Исправлена редкая ошибка, из-за которой в видео посреди просмотра могли попадать битые фрагменты. Если видели короткие вспышки артефактов — их больше нет.
- Поток, который раз за разом падает, теперь честно останавливается, а не перезапускается бесконечно.
- Много мелких правок интерфейса: страница уведомлений аккуратно ведёт себя на телефоне, а навигация больше не оставляет изредка пустую страницу.

## Webtor исполнилось 8 лет

И ещё одно: 26 августа проекту стукнуло восемь. [Первая версия](https://web.archive.org/web/20180826163118/https://webtor.io/) webtor.io открылась 26 августа 2018 года — одна страница с простым обещанием: смотреть торренты онлайн. Восемь лет спустя это плеер, библиотека, долгосрочное хранилище, Stremio, приложение для терминала и версия, которую можно целиком запустить на своём железе. Спасибо, что вы с нами всё это время.

Скоро будет ещё.
